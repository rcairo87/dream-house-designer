Dream House Designer — Version 3

LOCAL TEST
1. Extract the ZIP.
2. Open index.html in Chrome.
3. Build a test floor plan.
4. Save and reload the page to verify browser-local saving.

HOSTING
Upload index.html to a GitHub Pages repository. No server or database is required.

IMPORTANT
Save/Load uses browser localStorage. A project saved on one Chromebook/browser does not automatically appear on another device.
